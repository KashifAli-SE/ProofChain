## Task 5 — Agents 2 and 3: deterministic core

### Files to create
- `src/lib/agents/cross-checker.ts` — `runChecks(batch, extractions, now: Date): Finding[]`
  All 8 rules: `CERTIFICATE_DATE_VALIDITY`, `CERTIFICATE_NOT_EXPIRED_NOW`, `SUPPLIER_NAME_MATCH`, `BATCH_ID_MATCH`, `RECYCLED_CONTENT_VALUE_MATCH`, `QUANTITY_CONSISTENCY`, `REQUIRED_EVIDENCE_PRESENT`, `ENERGY_DATA_PRESENT`.
  Name normalisation helper (lowercase → strip punctuation → drop tokens `ltd/limited/pvt/private/inc/llc/co/company` → collapse spaces).

- `src/lib/agents/climate-analyst.ts` — `computeCarbon(activity: ActivityData, factors: typeof emissionFactors): CarbonResult`

- `src/lib/agents/status-policy.ts` — `deriveCeiling(findings: Finding[], carbon: CarbonResult): Recommendation` + `clamp(llm, ceiling)` using `RANK` map

## Task 6 — Agent 4 and Orchestrator

### Files to create
- `src/lib/agents/auditor.ts` — LLM call with system+user prompt from `docs/AGENT_SPECS.md`; post-processing: (a) drop uncited statements, (b) clamp recommendation to ceiling, (c) force `UNSUPPORTED` where REQUIRED_EVIDENCE flagged, (d) force `CONTRADICTED` on direct-value mismatch; fallback report when LLM fails twice
- `src/lib/agents/orchestrator.ts` — `runPipeline(batchId: string): Promise<RunResult>`:
  1. Create run row (`RUNNING`), lock with `one_running_run_per_batch` unique index → `RUN_IN_PROGRESS`
  2. Load batch + evidence + activity data
  3. `extractText` per document → Agent 1 per document
  4. Agent 2 → Agent 3 → `deriveCeiling` → Agent 4
  5. Persist `findings`, `carbon_result`, `audit_report`, `recommendation_ceiling`, `ai_recommendation`; set run `COMPLETED`, batch `IN_REVIEW`
  6. On any throw: set run `FAILED`, restore previous batch status, write audit entry
- `src/app/api/batches/[id]/analyze/route.ts` — `POST`: `RUN_IN_PROGRESS` guard, `NO_EVIDENCE` guard; calls orchestrator; returns `{ runId, status }`
- `src/app/api/batches/[id]/report/route.ts` — `GET`: returns latest run with full agent results for polling

### UI additions (in `src/app/batches/[id]/page.tsx`)
- "Run analysis" button with polling (`/api/batches/:id/report` every 2 s until `COMPLETED`/`FAILED`)
- Report view:
  - Findings grouped: **Verified-by-check** (PASS), **Inconsistent** (FLAG), **Missing** (UNKNOWN on REQUIRED_EVIDENCE), **Unverified** (other UNKNOWN)
  - `FindingCard` component: rule id, severity badge, finding text, evidence ids, reason
- `CarbonPanel` component: per-line table (kind, quantity, unit, factor id, factor value, factor source, kgCO2e); total; `ILLUSTRATIVE_FACTORS` warning tag; boundary statement; assumptions list

### Test files to create
- `tests/auditor-postprocess.test.ts` — fake LLM output containing an uncited statement + over-optimistic recommendation; verify statement dropped and recommendation clamped; verify fallback report structure

### Files to add components to
- `src/components/FindingCard.tsx`
- `src/components/CarbonPanel.tsx`
